# Nestlin v0.2.0

## Highlights

This release candidate introduces portable desktop distributions with a bundled Java 21 runtime, alongside platform-specific runnable JARs. It includes Nestlin's current keyboard/gamepad input, NTSC/PAL emulation, save states, battery saves, rewind, cheats and optional softcore RetroAchievements integration.

Recent changes fix RetroAchievements sign-in and reduce CPU, PPU and audio allocations. Compatibility evidence and board-specific limits remain in [mapper support](../../MAPPER_SUPPORT.md).

## Downloads

Choose `nestlin-v0.2.0-<platform>` for your operating system and CPU: Windows x86_64 (ZIP), Linux x86_64 (tar.gz), macOS Intel x86_64 or Apple Silicon aarch64 (tar.gz). Extract the entire archive and run `Nestlin/Nestlin.exe`, `Nestlin/bin/Nestlin`, or `Nestlin.app`. Java is included. Supply your own legally obtained ROM through File > Open.

The matching `.jar` is an alternative for users with Java 21. Native RA ZIPs are build-time integration assets, not the emulator. Verify downloads against `SHA256SUMS.txt`.

## Known limitations

Nestlin is a hobby emulator; mapper 5 remains a stub. A routed mapper does not guarantee every game works. RetroAchievements is optional and softcore-only. Gamepad support depends on JInput and the host device. Linux requires a graphical desktop and JavaFX system libraries. The portable images are unsigned; Windows SmartScreen and macOS Gatekeeper may require local approval. Automated headless smoke checks do not prove interactive audio, gamepad or display behavior; perform the manual acceptance checklist before publishing.

## Save compatibility

This release process does not change `.nstl` snapshot or `.sav` battery-save formats. Back up saves before upgrading; emulator state compatibility remains governed by the version encoded in each snapshot. See the [user guide](../USER_GUIDE.md) for save locations.
